# 🌿 Sulochana Foundation Web Application

Official web platform for **Sulochana Foundation** — a Mumbai-based social impact foundation dedicated to community healthcare, education, environmental sustainability, and women empowerment.

---

## 🚀 How to Clone and Run This Project

### Prerequisites
Make sure you have **Node.js** (v18 or higher) and **Git** installed on your system.
- Download Node.js: [https://nodejs.org/](https://nodejs.org/)

---

### Step 1: Clone the Repository
`ash
git clone https://github.com/adityazx7/sulochana-foundation.git
cd sulochana-foundation
`

---

### Step 2: Install Dependencies
Navigate into the project directory and install the required packages:

`ash
cd sulochana-foundation
npm install
`

---

### Step 3: Run the Development Server
Start the local Vite development server with live hot-reload:

`ash
npm run dev
`

Once started, open your browser and go to:
👉 **[http://localhost:3000](http://localhost:3000)** (or the port displayed in your terminal, e.g., http://localhost:5173)

---

### Step 4: Build for Production (Optional)
To create an optimized production build in the dist/ folder:

`ash
npm run build
`

To preview the production build locally:
`ash
npm run preview
`

---

## 🛠️ Tech Stack & Libraries
- **Framework**: [React 18](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Animations / Effects**: [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)
- **Typography**: Plus Jakarta Sans & Inter

---

## 📋 Core Initiatives
1. **Healthcare**: Voluntary blood donation camps & free health check-ups.
2. **Education**: 10th/12th admission counseling, book/notebook distributions, and competitive exam support.
3. **Environment**: Tree plantations, farmer guidance, and agricultural technology support.
4. **Social Welfare**: Government scheme welfare awareness and women empowerment through tailoring & vocational training.
